# Distribución de QR Sucursal para Windows

No se debe copiar solamente el archivo `qr_sucursal.exe`.

Para usar la aplicación en otra computadora:

1. Copia `QR_Sucursal_Windows_x64_COMPLETO.zip`.
2. Extrae todo el ZIP en una carpeta de la computadora de destino.
3. Ejecuta `qr_sucursal.exe` dentro de esa carpeta.
4. No muevas el ejecutable fuera de la carpeta ni elimines `data` o las DLL.

El paquete incluye el ejecutable, Flutter, todos los plugins, los recursos y las
bibliotecas de Microsoft Visual C++ requeridas. No es necesario instalar Flutter
ni volver a compilar. Este paquete es para Windows x64.

Cuando la aplicación avise que existe una actualización, **Actualizar** abre en
el navegador el ZIP completo publicado en Supabase. Descárgalo, extrae todos sus
archivos y reemplaza la carpeta anterior con la aplicación cerrada. **Ahora no**
o el botón de cierre permiten seguir usando la versión instalada.
